## 1. 我们要的到底是什么（大白话）

上位机（电脑上的软件）要和板卡配合工作，需要提前约定四件事：

1. **怎么连**：串口用哪根线、多快（波特率）；网口用哪个 IP/端口。
2. **怎么说话**：电脑发"开始采集"，板卡回"收到"；命令长什么样、出错怎么回。
3. **数据长什么样**：一帧数据在网线上是一串字节，要约定从头到尾每个字节是什么意思（帧头、序号、采样点）。
4. **出问题怎么发现**：丢了一包、序号跳了、校验错了，软件要能计数并告警，而不是悄悄少一帧。

这些约定写成文档就是**协议**。我们先按经验起草了 [v0.1 草案](v0.1.md)，你只需要用真实情况纠正它，不需要从零写。

## 2. 最小必答集（先回这 10 题就能开工）

| 编号 | 问题（不用专业术语也能答） | 一句话原因 |
|---|---|---|
| M1 | 数据口是网线吗？用 UDP 还是 TCP？电脑这边 IP/端口是多少？板卡往哪发？ | 决定数据怎么收、收在哪 |
| M2 | 一帧数据在网线上大概长什么样？有没有现成协议文档、SDK、demo 程序或抓包文件？ | 有现成的就不用猜 |
| M3 | 采样位数多少（12/14/16 位）？最高采样率多少？一帧最多多少个采样点？ | 决定内存、带宽、幅度换算 |
| M4 | 板卡同时能采多少个接收通道？探头最多多少阵元？ | 决定能力声明和界面通道数 |
| M5 | 串口参数：波特率多少？8 数据位/无校验/1 停止位（8N1）？有没有流控？ | 决定电脑怎么打开串口 |
| M6 | 有没有现成的"命令表"（发什么字节、回什么字节）？固件版本不同命令会变吗？ | 决定控制面怎么写 |
| M7 | 帧序号是谁加的（FPGA 还是固件）？丢数据/溢出时有没有标志位？ | 决定丢帧能不能被计数 |
| M8 | 数据是小端还是大端？有没有校验（CRC/和校验/以太网 FCS）？ | 决定怎么解包和对错 |
| M9 | 采集怎么触发：软件命令、外部触发、编码器？ | 决定启动/停止时序 |
| M10 | 板卡有没有"回环/仿真模式"？能不能借一台样机或测试台给我们联调？ | 没硬件时也能测到真实协议 |

**回答格式**：数字 + 单位 + 一句话例子。比如"最高采样率 80 MSPS，即每秒 8000 万次采样"。[示例文档](hardware-info-example.md) 里每题都有示范。

## 3. 你们给的答案会变成什么（为什么不是"随便问问"）

| 答案 | 用在上位机的哪里 | 如果答错会怎样 |
|---|---|---|
| 采样位数 | 幅度换算（满量程） | 幅度百分比全错，而且错得不明显 |
| 最高采样率 / PRF | 能力声明、参数校验 | 参数下发了但板卡做不到，采集中途出错 |
| 单帧最大点数 | 帧缓冲、队列容量 | 帧过大时内存不够或丢帧 |
| 接收通道/阵元数 | 能力声明、界面通道选择 | 界面显示的通道数不对 |
| 串口参数 | 打开控制口 | 连不上或收到乱码 |
| UDP 端口 / MTU | 数据口、缓冲区大小 | 收不到包，或大帧被网络丢掉 |
| 帧头字段 / 字节序 / 校验 | 解包代码 | 数据解析全错（现象是"有数据但数值离谱"） |
| 序号 / 溢出标志 | 丢帧计数、判伤完整性 | 丢了帧却以为没丢（探伤软件里这是严重问题） |
| 触发方式 | 启停时序 | 采到的帧和实际工件不同步 |
| 回环/样机 | 无硬件测试 | 只能等板卡到了才发现协议对不上 |

## 5. 不知道怎么办

在题号后面写清楚是哪种：

- **不知道**：写"不知道"，我们按默认假设做；
- **待确认**：写"待确认，预计 X 月 X 日"，我们先按默认做；
- **找某人**：写"找张工（固件）"。

默认假设（依据 [协议 v0.1 草案](v0.1.md)，如果没人纠正我们就先用这些）：

| 项 | 默认假设 | 后果 |
|---|---|---|
| 串口 | 921600，8N1，无流控 | 连不上时改设置即可 |
| 数据口 | UDP，端口 5000 | 收不到包时改端口 |
| MTU | 1500，不开 Jumbo | 大帧需要分片（暂不支持） |
| ADC | 16 位有符号右对齐 | 幅度换算按 16 位 |
| 单帧 | ≤16384 点/通道 | 超过会拒绝 |
| 序号 | 固件生成，步长 1 | 断档按丢失计 |
| 溢出标志 | 溢出后第一帧置位 | 没标志就检测不到设备侧丢帧 |
| 字节序 | 小端 | 大端会解析错 |
| 校验 | CRC32/ISO-HDLC | 没有校验就只能信网络 |
| 回环 | 有 | 没有就只能等样机 |

## 8. 小词典（不用记，看不懂时查）

| 词 | 大白话 |
|---|---|
| 波特率 | 串口每秒传多少个二进制位，常见 921600 |
| 8N1 | 8 个数据位、无校验（None）、1 个停止位，最常见的串口格式 |
| UDP | 一种"发出去不管到没到"的网络传输，快但可能丢包 |
| MTU | 一个网络包最多装多少字节，普通以太网约 1500 |
| FIFO | 板卡上的"临时仓库"，采太快先存着，满了就丢 |
| 采样率 | 每秒采多少个点，50 MSPS = 每秒 5000 万个点 |
| PRF | 每秒发多少次脉冲，决定一帧接一帧的节奏 |
| 触发 | 什么时候开始采：软件说开始、外部信号、编码器位置 |
| 编码器 | 装在机械轴上、能报告位置/速度的传感器 |
| 校验（CRC） | 给数据算一个"指纹"，收方重算，不一样就说明坏了 |
| 分片 | 一帧太大，拆成几个网络包装，收方再拼起来 |
| 字节序 | 一个数字在内存里的先后顺序：小端=低位在前 |
| 回环模式 | 板卡自己造数据发出来，不用接探头，用来测协议 |
